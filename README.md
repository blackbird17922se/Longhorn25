# 🖥️ Longhorn Web UI

Una interfaz web inspirada en el sistema operativo **Windows Longhorn (Build 4074)**, creada con tecnologías **vanilla (HTML, CSS y JavaScript)**. Este proyecto busca recrear la estética, fluidez y experiencia visual de Longhorn, manteniéndose fiel a su esencia: **transparencias, sombras, bordes suaves, gradientes horizontales y componentes flotantes**.

## 🎯 Objetivo

Crear una interfaz tipo sistema operativo como experiencia frontend completa, sin depender de frameworks como Angular o React. Longhorn Web UI demuestra que se puede lograr **una experiencia visual rica, estructurada y moderna** solo con tecnologías puras y buenas prácticas.

## 🚀 Características destacadas

- 🎨 Barra de tareas (Taskbar) fija con estética Aero
- 🪟 Menú de inicio flotante con efecto blur y comportamiento dinámico
- 🧊 Uso de `backdrop-filter` para lograr efectos tipo "glass"
- 💡 Interacción realista (abrir/cerrar menú, eventos fuera del menú)
- 🖼️ Diseño responsive con atención a detalles en pantallas grandes y pequeñas
- 🧩 Organización modular para permitir escalabilidad futura (ej. simulación de ventanas, paneles laterales, accesos rápidos)

## ⚙️ Tecnologías usadas

- HTML5
- CSS3 (Custom properties, Flexbox, Grid, `backdrop-filter`)
- JavaScript (DOM API, eventos, lógica de visibilidad)
- Bootstrap (solo para botones básicos)

## 📐 Inspiración

Longhorn fue una versión conceptual de Windows que jamás llegó al mercado oficialmente, pero dejó una huella visual imborrable. Este proyecto rinde homenaje a esa idea inacabada, llevándola al mundo web con amor por los detalles.
